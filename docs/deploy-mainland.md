# 部署到阿里云 / 腾讯云（大陆机房，要走备案）

这份是 `deploy-vps.md` 的**大陆版**：机器、部署脚本、备份、HTTPS 全部一样，
多出来的是**备案**这一段，以及大陆机房特有的几个坑。

先读 §0 判断你到底该不该走这条路。急的话直接跳到 §1 照抄。

---

## 0. 大陆机房 vs 香港机房

| | 大陆（阿里云/腾讯云轻量） | 香港（同样的机器，见 deploy-vps.md） |
| --- | --- | --- |
| 备案 | **必须**，域名不备案不能解析到这台机器对外提供服务 | 不需要 |
| 上线时间 | 买机当天能装，**备案要等 1–20 个工作日** | 当天上线 |
| 国内延迟 | 10–40ms，稳 | 30–80ms，晚高峰可能抖 |
| 带宽 | 3–5M 固定带宽（轻量常见） | 峰值 30M 但走国际线路 |
| 价格 | 轻量 2C2G ≈ 60–100 元/月（活动价常 24–45） | 同价或略高 |
| 风险 | 备案被退回、内容抽查、**留言板/图片上传可能被要求整改** | 基本没有行政风险，只有线路风险 |

**结论**：如果这个站要长期挂、要给国内的人稳定打开，走大陆 + 备案是正解；
如果只是想先上线看看，香港一份钟就能跑（`deploy-vps.md`），以后想搬再搬——
数据就是一个 SQLite 文件，搬起来不疼。

## 1. 下单前：三件事按顺序做

### 1.1 域名（备案的前提是域名已实名）

- 在阿里云（万网）或腾讯云买，`.com` / `.cn` 都行，**别买 `.top`、`.xyz` 这类**（部分管局对后缀有限制，且容易被判定低质）。
- 买完立刻做**域名实名认证**：上传身份证，1–3 个工作日通过。`.com` 没实名不能解析。
- 记住：域名注册人必须 **= 备案主体（你本人）**，名字差一个字都可能被退回。

### 1.2 云服务器（必须满足备案的资源条件）

腾讯云官方口径（阿里云基本一致，具体以控制台为准）：

- 地域：**中国境内**（香港/境外不能用于备案）；
- 计费：**包年包月**，竞价/按量不行；
- 时长：**≥ 3 个月**，且备案期间剩余有效期 **≥ 1 个月**；
- 必须带公网 IP、带宽不能为 0。

所以：**别买 1 个月试水**，直接 3 个月起。个人账号同一实例最多备 5 个网站（够用）。

推荐配置：轻量应用服务器 **2 核 2G / 40G 系统盘**，地域选离你近的（备案归属地按**身份证省份**，不按服务器地域）。

镜像只选「**系统镜像 → Ubuntu 24.04 LTS 64 位**」，没货再退 22.04：

- 支持到 2029，Docker、Caddy 的官方文档都按它写，`deploy-vps.md` 里的命令也全是 Ubuntu 的；
- **别选**应用镜像（宝塔 / LAMP / Node 预装），预装的 Web 服务器会和 Caddy 抢 80/443，还白占内存；
- **别选** CentOS 7 / 8（已停止维护）或 Alibaba Cloud Linux、TencentOS（能跑，但出问题时搜到的都是 Ubuntu 的解法）；
- 架构用默认的 **x86_64**。本项目镜像是多架构的（`Dockerfile` 基于 `node:24-slim`），ARM 实例也能跑，但 2C2G 这档没必要为省几块钱折腾。

进系统第一件事：`sudo timedatectl set-timezone Asia/Shanghai`；1G 内存的机器再补 1G swap（2G 可省）。

### 1.3 备案服务码 / 授权码

- 阿里云：备案控制台 → 备案服务码 → 从你的实例申请（每个实例最多 5 个，免费）。
- 腾讯云：控制台 → 备案 → 备案授权码（个人账号的轻量实例直接生成）。

拿到码才能提交备案，先申请好。

## 2. 备案：完整流程

入口：

- 阿里云 <https://beian.aliyun.com/>
- 腾讯云 <https://console.cloud.tencent.com/beian>

两家流程几乎一样，下面按顺序走。

### 2.1 主体信息（个人）

- 姓名、身份证号、手机号、邮箱、**详细住址（精确到门牌号）**；
- 手机号必须是**你本人实名**的，且能接收核验短信；
- 邮箱要能收件（管局可能发核验邮件）。

### 2.2 网站信息

| 项 | 怎么填 | 容易错的地方 |
| --- | --- | --- |
| 网站名称 | 「EdwardXiao 的个人主页」这类 | **不能**含公司、工作室、官方、论坛、社区、中国、国家、门户；个人站不要写「XX 博客平台」 |
| 域名 | 已实名的那个 | 一个备案可以填多个域名（同主体），但每个都要实名 |
| 服务内容 | 选「个人空间 / 博客」或最接近的 | 不要选「论坛」「社区」「电商」——选了就要额外资质 |
| 网站负责人 | = 你本人 | 个人备案不能换别人 |
| 备注 | 「个人主页，展示项目与活动记录；留言需审核后显示」 | 主动说明留言有审核，比被抽查时解释强 |

### 2.3 核验与提交

1. 上传身份证正反面（拍照要清晰、四角完整）；
2. 手机装**阿里云 APP / 腾讯云 APP** 做人脸核验（幕布拍照已经取消了，现在是 APP 里刷脸）；
3. 提交 → 云厂商初审（1–2 个工作日，会被打电话核实，接好）；
4. **工信部短信核验**：收到 `12381` 短信后 **24 小时内**按提示回复，超时要重新提交；
5. 管局审核：**1–20 个工作日**（各省不同，江浙沪快一些）。

### 2.4 备案期间的两条铁律

- **域名不要解析到这台大陆服务器**去提供服务。备案核验时如果发现域名已经能打开，会直接退回；
- 想先装环境、跑测试，用**公网 IP 直连**（80/443 在大陆机房对未备案域名是拦的，但 IP 一般能通，够你调试）。

## 3. 备案通过后：上线

1. **解析域名**：A 记录 → 服务器公网 IP（阿里云云解析 / 腾讯云 DNSPod），等 `ping 域名` 出 IP。
2. **部署**：照 `deploy-vps.md` §2–§7 走（装 Docker → 拉代码 → `.env` → `./deploy.sh` → 接域名 + HTTPS）。
   大陆机器只需要额外把镜像源换掉，见 §5。
3. **挂备案号**（法律义务，不挂会被要求整改）：

`.env` 里加一项（顺便给页脚用）：

```ini
ICP_BEIAN=京ICP备2026xxxxxx号
```

代码侧两处小改：

```ts
// src/data/site.ts —— 在 SiteInfo 里加字段
icp: '京ICP备2026xxxxxx号',   // 没备案就留空字符串
```

```astro
<!-- src/components/Footer.astro —— 放在 footer-line 里 -->
{site.icp && (
  <a class="icp" href="https://beian.miit.gov.cn/" target="_blank" rel="noopener nofollow">
    {site.icp}
  </a>
)}
```

样式（`footer` 的 `<style>` 里加）：

```css
.icp {
  color: var(--text-muted);
  text-decoration: none;
}
.icp:hover { color: var(--accent); }
```

4. **公安联网备案**：网站开通后 **30 日内**去 <https://beian.gov.cn/> 注册提交（填 ICP 号、域名、服务器 IP、接入商），审核通过后把「公网安备 xxxxxxxx 号」也挂到页脚。

## 4. 你这个站特有的合规点（重点看）

你的站不是纯静态博客，有三处会被管局/内容抽查盯上：

| 功能 | 风险 | 建议 |
| --- | --- | --- |
| 留言板（UGC） | 部分省管局要求个人站不得开设交互功能 | 保留**审核制**（现在是 `MODERATION=on`），并在页面写明「审核后显示」；必要时能一键关掉 |
| 图片上传 | 用户上传的内容，责任在站长 | 保留人工审核；限制类型/大小（现在 3 张 / 5MB）；留一个 `UPLOAD=off` 开关，被要求时直接关 |
| 收集昵称/邮箱/图片 | 属于收集个人信息 | 加一个 `/privacy` 说明收集什么、存多久、怎么删（现在没有这页） |

另外两条容易忽略的：

- **网络日志留存 ≥ 6 个月**（《网络安全法》第 21 条）。你现在的 Caddy 访问日志默认落盘，确认别关；`docker compose logs` 也留着。
- **不得有经营性内容**：个人备案不能挂广告位、付费入口、导流链接。页脚那三个社交链接没问题。

> 备案通过≠一劳永逸：管局会抽查，网站名称、内容、备案号任何一项对不上都可能被要求整改。

## 5. 大陆机房部署差异（相对香港版）

```bash
# Docker 换成国内源（腾讯云/阿里云都有镜像加速器，控制台可查个人加速地址）
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<'EOF'
{ "registry-mirrors": ["https://<你的加速器地址>.mirror.aliyuncs.com"] }
EOF
sudo systemctl restart docker
```

- **apt 慢**：换成 `mirrors.aliyun.com` / `mirrors.cloud.tencent.com` 的源；
- **带宽小**（3–5M）：首屏图片已经压成 WebP，问题不大；如果照片多，考虑把 `src/assets` 的图再压一档（`sharp` 质量 70）；
- **证书**：Caddy 一样能签，前提是 **80 端口对公网开放**（安全组 + `ufw` 两步都要）；
- **时区**：`sudo timedatectl set-timezone Asia/Shanghai`，否则备份时间会差 8 小时。

## 7. 上线验收清单

按顺序打勾，任何一项不过就别宣布上线：

- [ ] `curl -s localhost/healthz` 返回 `{"ok":true,...}`
- [ ] **手机 4G/5G**（关 WiFi）打开 `https://你的域名/`，首页正常
- [ ] 项目页、活动页照片都加载出来（不是裂图）
- [ ] 留言板发一条 → 进审核 → 后台通过 → 前台出现
- [ ] `/admin` 能登录，密码不是默认值
- [ ] 页脚能看到 ICP 备案号，点进去是 beian.miit.gov.cn
- [ ] 公安备案号（拿到后）也在页脚
- [ ] `docker compose ps` 两个容器都 healthy
- [ ] 备份 cron 跑过（`ls backups/` 有当天文件）
- [ ] `./deploy.sh --pull` 能完成一次滚动更新
- [ ] 浏览器控制台无报错、无混合内容警告
- [ ] 用 [itdog.cn](https://www.itdog.cn/) 从多地 ping 一次，确认解析和可达性

## 8. 常见退回原因（备案）

| 退回理由 | 原因 | 怎么改 |
| --- | --- | --- |
| 网站名称不合规 | 含「工作室」「论坛」「中国」等 | 改成「XX 的个人主页 / 博客」 |
| 域名未实名 / 实名信息不一致 | 注册人写的是别人或没做实名 | 过户到你本人 + 补实名 |
| 主体信息不完整 | 住址只写到小区 | 精确到门牌号 |
| 备案期间网站可访问 | 域名已解析并对外服务 | 先撤解析，只留 IP 调试 |
| 手机号核验超时 | 24 小时内没回 12381 短信 | 重新提交，立刻回复 |
| 服务器时长不足 | 买了 1 个月 / 按量计费 | 续费到 ≥3 个月包年包月 |
| 内容与网站名称不符 | 叫「技术博客」实际是项目展示 | 名称和内容对齐 |

## 9. 如果备案被卡住

- 换省/换主体信息重提（同一主体同一域名重复提交有限制，先问客服）；
- 先上香港（`deploy-vps.md`）跑着，备案下来再迁移——数据库就是 `data/guestbook.db` + `data/uploads/`，拷过去就行；
- 备案期间不要买「备案代办」，官方备案 0 费用，代办除了一些省要求接入商代为提交外没有额外价值。
