给 DeepSeek Harness 做的插件 **dsh-run-button** 收录进了社区精选列表 awesome-dsh-plugin，
提交的 PR（#5617）已经合并。现在在 DSH 的插件市场里搜 `dsh-run-button` 就能找到并安装。

插件干的事很简单：给回复里的命令行代码块加一个「运行」按钮，点一下就在宿主机执行，
输出实时流到浮动面板。之后我把它发到 npm，预编译包附在 GitHub Release 上，
别人不装工具链也能用。最后去 awesome-dsh-plugin 提交了条目，市场里就搜得到了。
